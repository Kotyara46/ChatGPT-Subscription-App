# GPT Direct for Android

Нативный Android-клиент для прямого общения с моделями OpenAI. Это не WebView и не набор ссылок: сообщения отправляются в OpenAI Responses API, а ответы отображаются прямо внутри APK.

## Что уже работает

- полноценный чат внутри приложения;
- GPT-5.6 Sol / Terra / Luna на выбор;
- продолжение контекста через `previous_response_id`;
- встроенный web search по переключателю;
- отправка изображений на анализ;
- голосовой ввод через Android;
- локальная история диалога;
- новый чат одной кнопкой;
- копирование ответа долгим нажатием;
- русский интерфейс;
- два режима подключения: личный прямой API и безопасный сервер-посредник.

## Безопасность

OpenAI не рекомендует хранить обычный API-ключ в мобильном клиенте. Поэтому для постоянного использования предусмотрен серверный режим. В репозитории есть `api/chat.js` — минимальный Vercel endpoint, который хранит `OPENAI_API_KEY` только в переменной окружения сервера и проксирует запросы в OpenAI.

Прямой режим оставлен для личной установки и быстрого теста. Ключ не зашивается в APK и не попадает в GitHub: пользователь вводит его на устройстве, после чего он шифруется ключом из Android Keystore.

## Vercel backend

1. Подключить этот репозиторий к Vercel.
2. Добавить server environment variable `OPENAI_API_KEY`.
3. Опционально добавить `APP_TOKEN`.
4. После деплоя в Android-приложении включить «Использовать защищённый сервер» и указать `https://<domain>/api/chat`.
5. Если задан `APP_TOKEN`, ввести тот же токен в настройках приложения.

Никогда не коммитьте API-ключ в этот репозиторий.
