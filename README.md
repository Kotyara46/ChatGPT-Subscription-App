# ChatGPT Plus Контроль

Нативное Android-приложение на русском языке для контроля ChatGPT Plus.

## Возможности

- быстрый переход в официальный ChatGPT;
- управление оплатой через официальный Billing;
- переход на покупку/продление Plus;
- открытие подписок Google Play, если ChatGPT был оформлен через Android;
- локальное сохранение статуса подписки;
- сохранение крайнего срока оплаты/отключения;
- уведомления за 3 дня, за 1 день и в день срока;
- копирование диагностической информации;
- ссылки на официальную справку и поддержку OpenAI.

Приложение не хранит пароль ChatGPT, банковские карты или cookies. OpenAI не предоставляет публичный API для чтения срока личной подписки Plus, поэтому приложение не выдумывает автоматический статус: оно открывает официальный Billing, а подтверждённый пользователем статус сохраняет локально.

## APK

GitHub Actions автоматически собирает устанавливаемый `ChatGPT-Plus-Control.apk` после изменений в ветке `main`.
